# QCloud2 Client

Front-end (Angular) for QCloud, a quality control platform for mass spectrometry instruments.

## Tech stack

- Angular
- Node.js / npm

## Getting started (development)

Requirements: Node.js, npm, Angular CLI (`npm install -g @angular/cli`).

```
npm install
ng serve
# App available at http://localhost:4201
```

See [qcloud2-server](https://github.com/proteomicsunitcrg/qcloud2-server) for the backend counterpart.
